Backend folder
1. pip install fastapi uvicorn 
(fastapi - web framework for building APIs with Python;
 uvicorn - ASGI (Asynchronous Server Gateway Interface) web server designed for Python. 
        . The intermediary between client & FastAPI application.
        . It listens for incoming HTTP requests, processes & forwards them to FastAPI for handling.)
    To run FastAPI via Uvicorn: uvicorn "backend_python_file":app --reload
        (app: FastAPI instance inside the file.
         --reload: Automatically restarts the server when the code change)
2. To run "single_upload.py": python -m uvicorn singlefile_upload:app --reload
